# Postman + Documenter

## Archivos

- `docs/postman/Traldisporta_Client_API.postman_collection.json`

## Importar en Postman

1. Abre Postman.
2. Click en `Import`.
3. Selecciona `Traldisporta_Client_API.postman_collection.json`.
4. En la coleccion, define variables:
   - `baseUrl` (por defecto: `https://api-traldisporta.com/api/v1`)
   - `apiKey` (tu API key)

## Publicar documentacion

1. Abre la coleccion importada.
2. En el menu `...` de la coleccion, elige `Publish Docs`.
3. Configura titulo, visibilidad y dominio.
4. Publica.

Referencia: [Postman Documenter](https://documenter.getpostman.com/).
